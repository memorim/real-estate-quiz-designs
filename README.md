# Недвижимость — лендинг и квиз

Портфолио-концепции по предварительному запросу. Два детальных и три минималистичных направления.

**Статус:** дизайн-кейс для портфолио. Макеты подготовлены; полноценная разработка сайта не заявляется.

[Посмотреть галерею](https://memorim.github.io/real-estate-quiz-designs/)

## Что сделано
- 5 визуальных направления, отдельные компьютерные и мобильные композиции.
- Типографика, цвета, расстановка акцентов и основной призыв к действию.
- Адаптивная HTML-галерея для просмотра результатов без редактора.

## Материалы и ограничения
В [QUIZ.md](QUIZ.md) — вопросы и варианты ответов. В assets — PNG и редактируемые SVG. Третья детальная концепция, исключённая из итогового комплекта, не включена. Материалы не подтверждают актуальные цены, ипотечные условия или наличие квартир. Архитектурный визуал создан для концепции и не является фото фактического объекта. Marquiz и CRM не подключены.

## Запуск и проверка
Проверено с Python 3.12.14 только для локального сервера и проверки файлов. Сама галерея использует HTML и CSS без сборки и зависимостей.

```bash
python tests/check_assets.py
python -m http.server 8080
```

Открыть http://localhost:8080. Кнопки навигации галереи работают; элементы внутри макетов остаются изображениями.

## Реализация
Макеты показаны в исходных пропорциях: компьютерная и мобильная композиции подготовлены отдельно. Галерея использует CSS Grid и обычные HTML-ссылки, дополнительные экраны раскрываются через details. Данные посетителей не собираются.

## Проверка документации и обновлений

`python .github/scripts/check_docs.py` проверяет ссылки на файлы и изображения в Markdown, регистр имён и случайные локальные ссылки. Примеры команд внутри блоков кода не проверяются как ссылки. `--external` дополнительно проверяет публичные HTTP-ссылки: 404/410 считаются ошибками; авторизация, сетевые сбои и ограничения сервиса отмечаются как непроверенные. HTTP-проверка запускается еженедельно и вручную; локальные ссылки — при каждом push/PR. Фрагменты внутри страниц не проверяются.

Dependabot еженедельно предлагает сгруппированные обновления зависимостей и GitHub Actions. Автоматического слияния нет; обновления проходят CI. [История версии](CHANGELOG.md).
