# Анна Ермакова - квартиры на Сортировке

Адаптивный лендинг выбранной бело-синей концепции. На странице нет названия ЖК. Условия взяты из [публикации Анны](https://max.ru/ermakova_rieltor/AaFiUvV6eV8); цена и наличие уточняются при обращении. Изображение выбрано заказчиком из исходного макета.

[Открыть лендинг](https://memorim.github.io/real-estate-quiz-designs/anna-ermakova/) · [Открыть квиз напрямую](https://mrqz.me/6ae11332bacbcd000ffd4734)

## Как работает

Первый экран - обычные HTML/CSS без сборки. Кнопка открывает квиз `6ae11332bacbcd000ffd4734` из приглашённого проекта Анны в модальном окне Marquiz. На телефоне используется адаптивное окно на весь экран. Если скрипт заблокирован или ещё загружается, остаётся рабочая прямая ссылка на тот же квиз. Масштаб 125% применяется к лендингу, не к внешнему контейнеру модального окна.

Три вопроса: тип квартиры, бюджет и способ покупки. Контакты, согласие и заявки обрабатываются Marquiz. Этот репозиторий не хранит контакты посетителей, API-ключи и данные личного кабинета. Публичный ID квиза не является секретом.

На первом экране используется `tower.png` - исходный рендер из выбранной концепции, без полей скриншота. Изображение вписано через `object-fit: cover`; фокус смещён вправо, как в референсе. На компьютере общий масштаб интерфейса составляет 125%, на телефоне сохранена самостоятельная адаптивная версия.

## Локальная проверка

Из корня репозитория:

```sh
node tests/check_quiz.mjs
node tests/check_quiz_design.mjs
python -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://localhost:8080/anna-ermakova/`. Проверка JavaScript подтверждает обновление прогресса при переходе вперёд и назад, переход к форме и отсутствие повторных элементов оформления.

`marquiz-design.js` установлен через штатный раздел Marquiz «Интеграции - Свой код», внутри тега script. Он добавляет оформление и прогресс, не читает контакты, не меняет ответы и не выполняет сетевые запросы. После изменения разметки со стороны Marquiz нужно повторить визуальную проверку.

Inter размещён локально в `fonts/` с лицензией OFL. [Редактируемый макет Figma](https://www.figma.com/design/vTFD0OJk6tb7ygdDONQyfO?node-id=3-2) содержит компьютерную и мобильную версии, три вопроса, форму заявки и экран после отправки.

## Управление

Вопросы и форма меняются в редакторе Marquiz; затем изменения нужно опубликовать. Для сохранения оформления первого экрана редактируются `index.html` и `style.css`. Уведомления, тариф и политика обработки данных управляются в проекте Marquiz владельцем. Наличие одного лишь ID в коде не подтверждает доставку уведомлений или оплату тарифа.
