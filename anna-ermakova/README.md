# Анна Ермакова - квартиры на Сортировке

Адаптивный лендинг выбранной бело-синей концепции. На странице нет названия ЖК. Условия и рендер взяты из [публикации Анны](https://max.ru/ermakova_rieltor/AaFiUvV6eV8); цена и наличие уточняются при обращении.

[Открыть лендинг](https://memorim.github.io/real-estate-quiz-designs/anna-ermakova/) · [Открыть квиз напрямую](https://mrqz.me/6ae11332bacbcd000ffd4734)

## Как работает

Первый экран - обычные HTML/CSS без сборки. Кнопка использует официальный скрипт Marquiz v2 и открывает квиз `6ae11332bacbcd000ffd4734` из приглашённого проекта Анны. Если скрипт ещё не загрузился или заблокирован, ссылка открывает тот же квиз напрямую.

Три вопроса: тип квартиры, бюджет и способ покупки. Контакты, согласие и заявки обрабатываются Marquiz. Этот репозиторий не хранит контакты посетителей, API-ключи и данные личного кабинета. Публичный ID квиза не является секретом.

Рендер `courtyard.jpeg` - оригинальное вложение публикации, состоящее из двух изображений. CSS показывает верхнюю сцену двора. Изображение условной башни из ранней концепции здесь не используется.

## Локальная проверка

Из корня репозитория:

```sh
node tests/check_quiz.mjs
python -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://localhost:8080/anna-ermakova/`. Проверка JavaScript подтверждает совпадение ID прямой ссылки и виджета, работоспособность ссылки без загруженного скрипта и отсутствие автоматического открытия.

## Управление

Вопросы и форма меняются в редакторе Marquiz; затем изменения нужно опубликовать. Для сохранения оформления первого экрана редактируются `index.html` и `style.css`. Уведомления, тариф и политика обработки данных управляются в проекте Marquiz владельцем. Наличие одного лишь ID в коде не подтверждает доставку уведомлений или оплату тарифа.
